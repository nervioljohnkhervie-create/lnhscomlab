Equipment & Lab Policies

1. Equipment Borrowing

All students must present a valid LRN upon borrowing. Borrowed equipment must be returned on or before the agreed time slot.

2. Computer Station Use

Students must log their station in the Computer Lab Log upon sitting down and mark checkout when done.

3. Care of Property

Any technical malfunction or damage must be reported immediately to the computer laboratory in-charge.

Frequently Asked Questions

Q: Who can request equipment?

A: Anyone with a valid 12-digit LRN can submit a request form.

Q: How do I check out from a lab station?

A: Find your session row in the Computer Lab Log and click the "Checkout" link.

Q: Do changes show on other computers?

A: Yes! Changes automatically sync across open browser windows in the laboratory network.

How to Access across All ComLab Computers

This website is designed to run across all computers in your school computer laboratory connected to the same network.

1 Local Network Server Setup (No Internet Required)

  1. Save this file as index.html on the host/teacher PC.
  2. Open Command Prompt (cmd) on the host PC and type ipconfig to find your IPv4 Address.
  3. Start a web server (e.g. VS Code Live Server or Python: python -m http.server 8000).
  4. On all other student PCs in the lab, open the browser and enter the host IP and port (e.g., http://192.168.1.15:8000).
